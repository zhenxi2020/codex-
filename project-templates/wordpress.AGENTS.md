# WordPress 项目规则

本项目继承用户级 `~/.codex/AGENTS.md`。本文件只补充项目事实。

## 项目入口

- 主题源码：填写实际路径。
- 插件或 mu-plugin：填写实际路径。
- 当前状态：`tasks/current.md`；本轮计划与 Review：`tasks/todo.md`。

## 边界

- 可维护内容优先使用 WordPress 后台、原生配置或已有字段，避免写死。
- 不直接修改 `wp-admin`、`wp-includes` 等核心文件。
- 数据库、服务器、生产站、部署和版本升级必须在确认单中单独列出。
- 发布包、备份、截图和浏览器配置不是源码，未明确要求时不修改。

## 验证

- PHP 修改先做相关文件语法检查，再验证目标页面或后台入口。
- 公共模板和全局样式至少验证桌面端与移动端代表页面。
- 字段或数据修改验证保存、刷新、空值、旧数据和失败回滚。
