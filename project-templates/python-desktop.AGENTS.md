# Python 桌面软件项目规则

本项目继承用户级 `~/.codex/AGENTS.md`。本文件只补充项目事实。

## 项目入口

- 正式启动入口：填写真实文件和主窗口类。
- 数据目录、配置、数据库、日志和导出目录：填写实际路径。
- 正式打包脚本：填写唯一允许的构建命令。

## 边界

- 修改界面前先确认真实入口，避免只修改备用窗口或旧代码。
- 用户文件和正式配置只读；测试使用隔离数据根目录。
- 新字段提供旧配置默认值或迁移逻辑。
- 未明确要求发布时，不升级版本、不打包、不修改发布目录。

## 验证

- 先运行相关测试、语法检查和真实入口验证。
- 配置或数据库修改验证保存、重启、旧数据升级和失败回滚。
- 源码、构建、绿色版和安装版分别报告验证状态。
