# 信源统计助手项目规则

本项目继承 `C:\Users\Administrator\.codex\AGENTS.md`。本文件只补充扩展入口、平台边界和验证方式。

## 项目事实

- 这是 Chrome/Edge Manifest V3 扩展。
- `manifest.json` 定义权限、内容脚本和侧边栏；`background.js` 是模块化 Service Worker；`content.js` 负责各 AI 平台页面交互；`sidepanel.*` 负责界面；`domain.mjs` 负责域名处理。
- 正式源码是根目录文件。`信源统计助手-v2.1.22/`、RAR、ZIP 和 `output/` 属于旧版或发布产物，未明确要求发布时不修改。

## 修改边界

- 平台适配修改先锁定目标平台和真实失败阶段：登录检查、输入、发送、回答等待、来源面板、解析、收敛或恢复。
- 不绕过登录、验证码、限流、证书警告或浏览器安全机制。
- 修改 `manifest.json` 的权限或 host 权限时，确认必要性和升级影响，避免扩大权限。
- 修改 storage 结构、任务队列或历史记录时，提供旧数据默认值或迁移逻辑。
- 不把某个平台的选择器或状态判断复用到其他平台，除非已有共享抽象并完成回归。

## 验证

- 纯域名、状态机和数据逻辑优先运行：`node --test tests/regression.test.mjs`。
- 平台 DOM 修改除自动测试外，还要在目标平台真实页面验证；其他平台只在共享逻辑受影响时回归。
- Service Worker 修改验证休眠/重启后的状态恢复；侧边栏修改验证关闭再打开后的持久化。
- 未验证真实登录页面时，明确区分“自动测试通过”和“平台端到端已验证”。

## 发布边界

- 用户未明确要求发布时，不改版本、不复制发布目录、不生成 ZIP/RAR、不创建 Release。
- 发布前核对 `manifest.json` 版本、源码清单、测试结果和解压安装结果。
