# GPT 批量生图插件项目规则

本项目继承 `C:\Users\Administrator\.codex\AGENTS.md`。本文件只补充扩展入口、数据约束和验证方式。所有修改先只读调查并提交确认单，得到用户明确确认后再实施。

## 项目事实

- 这是 Chrome Manifest V3 扩展，正式入口由根目录 `manifest.json` 定义。
- `background/` 管理任务、标签页和持久化；`content/` 控制 ChatGPT 页面；`dashboard/` 是侧边栏；`shared/` 是共享逻辑；`scripts/` 是检查工具。
- `发布包/`、`output/` 和已有 ZIP 属于产物；未明确要求发布时不修改或重新生成。

## 不可破坏的业务约束

- 发给 ChatGPT 的文字只能由 Word 正文和控制台提示词按既定顺序组成，不添加产品名、文件名或隐式提示。
- 每个包含 Word 的目录必须绑定本目录唯一参考图，不跨目录寻找或复用。
- 暂停只停止领取新任务，不能中断已经执行的槽位；并发槽位、冷却、重试和输出路径保持隔离。
- 不绕过 ChatGPT 登录、验证码、额度或频率限制，不保存账号密码。
- 修改任务记录、目录句柄或配置结构时，验证旧数据兼容和浏览器重启恢复。

## 验证

- 单元测试：`npm test`。
- 扩展完整性检查：`npm run check`。
- 修改网页控制器、选择器、标签页调度或下载流程时，需要在已登录 Chrome 中做针对性端到端验证。
- 报告必须区分：静态检查、单元测试、扩展加载、真实生成、文件保存分别是否验证。

## 发布边界

- 用户未明确要求发布时，不升级 `manifest.json` 与 `package.json` 版本，不生成发布包。
- 发布时核对版本一致性、源码清单、解压加载、最小真实任务和输出目录结构。
