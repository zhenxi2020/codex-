# 项目最高优先工作规则

本项目后续协作默认遵循以下规则。除系统/开发者级更高优先指令外，均按本文件执行。

本项目同时继承 `C:\Users\Administrator\.codex\AGENTS.md`。每次开发任务先给出模型建议；所有代码、配置、文档、部署和数据修改都必须先只读调查并提交确认单，得到用户明确确认后才能实施。确认后在已批准范围内连续执行，范围实质变化时重新确认。

## 1. 计划模式默认开启

- 任何 **非琐碎任务**（通常指 3 步以上、涉及结构调整、跨页面联动、后台化、迁移、SEO、移动端、部署、数据同步）都必须先进入计划。
- 计划必须包含：
  - 目标范围
  - 受影响文件/页面
  - 验证步骤
  - 风险点
- 计划还必须写明不修改范围、回滚方式和是否需要 Agent Team，并在实施前由用户确认。
- 如果执行中发现目标偏移、用户补充口径、或实现方式明显不优雅，必须先停下并重排计划，不能硬着头皮继续改。

## 2. 一次只收一个页面 / 一个小范围

- 除非用户明确要求整批并行推进，否则默认：
  - 一次只处理一个页面
  - 或一个明确的小模块
- 做完后必须先验证，再进入下一个页面。
- 禁止“顺手改别的页面”“顺手统一全站”，除非已经在计划中写明并得到用户确认。

## 3. Agent Team / 子代理使用规则

### 何时启用 Agent Team

- 当任务可拆为 **2 个以上可并行的专项工作流** 时启用，例如：
  - 前端结构检查 / 移动端检查 / 后台可维护性检查 / SEO 检查
  - 安全 / 性能 / 测试 三线审查
- Team Lead 负责：
  - 拆任务
  - 提供上下文
  - 汇总结论
  - 处理接口、冲突、集成和最终验证
- Team Lead 可以承担关键路径或集成工作；不要为了形式空出一个代理席位。
- 创建团队前必须先在确认单中列出团队结构、分工和交付边界，由用户确认。

### Teammate 规则

- 每个 Teammate 只做一个专项。
- 指令必须自包含，不能假设 Teammate 已知道主会话历史。
- 能并行就并行；不能并行时不要硬拆。

### 何时退化为普通子代理

- 轻量调研
- 单次验证
- 没有横向通信需求的小问题

## 4. 后台优先，禁止前台写死

- 任何用户可长期维护的信息，优先放后台控制：
  - 页面正文
  - 特色图 / 缩略图
  - 菜单
  - 分类
  - 产品字段
  - 站点设置
- 能用 WordPress 原生、WPJAM、ACF、现有设置页实现的，不要写死在模板里。
- 如果暂时必须加 fallback：
  - 要写清 fallback 来源
  - 后续要有后台化回收计划

## 5. 先对照原站，再改

- 对已有线上站（EyouCMS）的迁移/对齐工作：
  - 先看原站当前逻辑
  - 再改 WordPress
- 不能凭想象“优化”，更不能偏离原结构后再解释。
- 如果用户要求“先同步原站”，就优先忠实对齐，而不是先做优化版。

## 6. 修改前的回滚保障

- Git 已跟踪且能可靠恢复的本地文件，以修改前状态和差异记录作为默认回滚依据，不额外复制大量备份。
- 未跟踪文件、数据库、服务器文件、生产配置和不可逆数据操作必须先备份。
- 备份路径和恢复方法记录到本次任务 Review 或交接文档。

## 7. 完成前必须验证

- 没验证通过之前，不能说“改好了”。
- 至少要做：
  - 语法检查
  - 目标页面前台检查
  - 必要时移动端检查
  - 必要时让专家复核
- 如果是迁移类或公共模块改动，要明确说明：
  - 影响范围
  - 是否会影响别的页面

## 8. 结果表达要求

- 只说已经真实验证过的内容。
- 不夸大，不抢跑，不用“应该”“大概”冒充已验证结果。
- 如果有残留问题，要直接指出。

## 9. 被纠正后必须沉淀教训

- 用户一旦纠正：
  - 立即在 `E:\wangzhan\tasks\lessons.md` 追加教训
  - 写清：
    - 误区
    - 正确做法
    - 下次如何避免

## 10. 任务管理落地文件

- 任务清单：`E:\wangzhan\tasks\todo.md`
- 教训记录：`E:\wangzhan\tasks\lessons.md`
- 迁移与交接记录：`E:\wangzhan\docs\wp-migration-handoff-20260424.md`

## 11. 当前项目特别口径

- 全程中文沟通。
- 修改时以“稳”为第一原则，避免把别的功能或页面带乱。
- 用户明确要求“不要跑偏”时，必须缩小范围执行。
- 能让专家检查的地方，尽量让专家参与复核。
- 测试站 `wp.zhikj.com` 现阶段必须保留 `noindex, nofollow`，未正式上线前不能建议去掉。
