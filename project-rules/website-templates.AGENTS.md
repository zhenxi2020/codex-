# 网站模板开发项目规则

本项目继承 `C:\Users\Administrator\.codex\AGENTS.md`。本文件只补充项目事实和验证边界。

## 项目结构

- 当前主题源码位于 `geo-health/`，是 WordPress/PHP 主题。
- 页面模板在 `geo-health/*.php`，公共逻辑在 `geo-health/functions.php` 与 `geo-health/inc/`，复用视图在 `geo-health/template-parts/`，静态资源在 `geo-health/assets/`。
- `方案.md`、`docs/` 和 `tasks/` 是需求、设计与任务记录；只读取当前任务相关章节。
- 根目录 ZIP、`output/`、备份文件和截图属于产物或证据，未经明确要求不修改、不重新生成。

## 修改边界

- 开始前先确认本轮目标站点、目标模板、桌面端/移动端范围和后台字段来源。
- 可长期维护的正文、图片、菜单、产品字段和站点信息优先由 WordPress 后台或已有字段提供，避免写死在模板。
- 修改公共函数、Header、Footer、全局样式或模板路由时，确认所有受影响页面。
- 不修改 WordPress 核心文件，不直接编辑备份 ZIP，不把测试内容写入正式站点。

## 验证

- PHP 修改先对相关文件运行语法检查；没有 PHP 环境时明确标注未验证。
- 页面修改至少验证目标页面；涉及公共布局时增加桌面端和移动端代表页面。
- 后台字段修改验证保存、刷新、空值回退和旧数据兼容。
- 非发布任务不制作 ZIP、不部署、不更新版本。

## 文档路由

- 当前任务和进度：`tasks/todo.md`。
- 最近相关纠错：按关键词读取 `tasks/lessons.md`，不要默认整份加载。
- 视觉或内容规范：仅在任务涉及对应页面时读取 `方案.md` 或 `docs/` 中相关文件。
